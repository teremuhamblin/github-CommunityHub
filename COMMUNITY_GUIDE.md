# Guide Communautaire
- GitHub-CommunityHub

Ce guide explique comment participer efficacement au projet GitHub-CommunityHub.

---

### 🧩 Types de contributions acceptées
```text
- Ajout de templates d’issues ou PR
- Ajout de workflows GitHub Actions
- Amélioration de la documentation
- Correction d’erreurs ou optimisation
- Propositions de bonnes pratiques GitHub
```

---

### 🛠 Processus de contribution
```text
1. Fork du dépôt
2. Création d’une branche dédiée
3. Ajout ou modification du contenu
4. Création d’une Pull Request
5. Respect du template PR
6. Attente de la revue d’un mainteneur
```

---

### 📌 Règles de qualité
```text
- Code clair et commenté
- Documentation obligatoire pour tout ajout
- Respect des conventions GitHub
- Pas de contenu offensant ou non constructif
```

---

### 🔐 Sécurité

Toute vulnérabilité doit être signalée via **SECURITY.md**.
