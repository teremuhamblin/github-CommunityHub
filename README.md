## 🟦 GitHub-CommunityHub

GitHub-CommunityHub est un dépôt communautaire dédié à la documentation, aux bonnes pratiques, aux templates et aux ressources permettant d’améliorer l’utilisation de GitHub au quotidien.

- Ce dépôt sert de hub central pour :
```text
- les templates d’issues et de pull requests  
- les workflows GitHub Actions  
- les guides de contribution  
- les bonnes pratiques de gestion de projets  
- les ressources pour les équipes et la communauté  
```

### 🎯 Objectifs
```text
- Centraliser les meilleures pratiques GitHub  
- Fournir des exemples concrets et réutilisables  
- Aider les développeurs à structurer leurs dépôts  
- Proposer des workflows modernes et sécurisés  
- Offrir un espace de documentation clair et accessible  
```

### 📁 Structure du dépôt
```text
- discussions/ — Guides et bonnes pratiques  
- examples/ — Templates et workflows prêts à l’emploi  
- .github/ — Configuration GitHub complète  
- COMMUNITY_GUIDE.md — Guide communautaire  
- github-resources.md — Ressources utiles GitHub  
```

### 🧩 Contenu principal

✔ Templates d’issues
Bug report, feature request, questions, etc.

✔ Templates de pull requests
Standardisés, propres, orientés qualité.

✔ Workflows GitHub Actions
CI, sécurité, auto-label, dépendances, etc.

✔ Guides communautaires
Comment contribuer, comment gérer les issues, comment structurer un dépôt.

✔ Ressources GitHub
Liens utiles, documentation, outils, bonnes pratiques.

### Issue Autoresponse — v1.0.0

### 🎯 Objectif
Ce workflow automatise la réponse à chaque nouvelle issue ouverte dans le dépôt **GitHub‑CommunityHub**.  
Il fournit un message d’accueil clair, professionnel et orienté communauté, tout en redirigeant les utilisateurs vers le dépôt officiel GitHub Feedback Discussions lorsque nécessaire.

### ⚙️ Fonctionnement
- Déclenchement automatique à chaque ouverture d’issue.
- Envoi d’un message préformaté au créateur de l’issue.
- Aucune action supplémentaire n’est effectuée (pas de fermeture automatique).
